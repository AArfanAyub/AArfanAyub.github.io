IMRI

Offline Library Management for School Resource Centres

Python Standard Library Only SQLite Offline-First Vanilla JS Zero Dependencies 180 Tests

A complete replacement for the paper borrowing register in a school library. It runs on one Windows PC with no internet, no installer, no database server and no account — the catalogue, members, loans, fines, reservations and reports all live in a single SQLite file you can carry on a USB stick. Built for Malaysian schools: Dewey classification, accession numbers, Bahasa Melayu / English / 中文 interface, RM currency and per-day fines. The backend is Python's standard library with no pip install; the frontend is hand-written ES modules with no bundler and no CDN. It binds to 127.0.0.1 only and makes no external request of any kind, so it works on a PC that has never been online.

Serambi POS Pro

Offline Point of Sale with Real Double-Entry Accounting

Windows Offline Point of Sale Double-Entry Accounting SQLite Inventory Ledger E-Invoicing

A desktop point-of-sale for small and medium businesses that works with no internet connection at all — one installer, one PC, no account, no cloud, no subscription. What separates it from a till is what sits underneath: a real double-entry ledger, so every sale, void and refund posts a journal entry automatically. Debits always equal credits, enforced at the database level rather than by the application remembering to do it. Posted entries cannot be edited or deleted, only reversed, so the record of what actually happened survives. Stock is tracked through a movement ledger instead of an editable number, which means the current quantity is always explainable. Shifts reconcile against the expected drawer, and exports go to CSV, Excel and PDF.
